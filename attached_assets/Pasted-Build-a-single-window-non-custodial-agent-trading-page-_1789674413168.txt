AUTH API (MVP)
POST /api/trade/auth/challenge
  body: { "address": "r..." }
  resp: { "address", "nonce", "expires_at", "message": "Pond Trade login\nAddress: r...\nNonce: ...\nDomain: pond.greenhead.io\nExpires: ISO8601" }
  (Message must be deterministic for sign-verify.)

POST /api/trade/auth/verify
  body: { "address", "nonce", "signature": "hex-or-base64 of signed message OR signed Payment-less Signers proof" }
  Prefer XRPL account signature over arbitrary message if you already have a pattern; otherwise signed UTF-8 message verify with classic address pubkey derivation.
  resp: { "token", "expires_at", "address" }
  On fail: 401.

GET /api/trade/session  (Authorization: Bearer <token>)
  resp: { "address", "balances": {"XRP", "PND"?}, "trustlines": [...], "network": "mainnet" }

PREPARE / SUBMIT API (MVP)
All require Bearer session.

POST /api/trade/prepare/trustset
  body: { "limit": "string amount", "currency": "PND"|hex, "issuer": "rPNDRmfNNrUZstkA23haCUkCp7qLEPnaYc" }
  resp: { "tx_json": {unsigned TrustSet}, "hash_to_sign_hint"?: string }

POST /api/trade/prepare/offer
  body: { "side": "buy"|"sell", "taker_gets": Amount, "taker_pays": Amount, "flags"?: number }
  Amounts: XRP as drops string OR {currency,issuer,value} for $PND.
  resp: { "tx_json": unsigned OfferCreate }

POST /api/trade/prepare/cancel
  body: { "offer_sequence": number }
  resp: { "tx_json": unsigned OfferCancel }

POST /api/trade/submit
  body: { "signed_tx_blob": "..." } OR { "tx_json": fully-signed }
  Server: decode → verify Account==session address → allowlist type ∈ {TrustSet,OfferCreate,OfferCancel} → submit to mainnet → resp { "engine_result", "hash", "accepted": bool }
  Also document client-direct submit path: agent may skip /submit and broadcast itself after prepare.

GET /api/trade/book?pair=PND_XRP&limit=20
  Public or auth’d order book snapshot (best bids/asks) for UI.

GET /api/trade/open-offers (auth)
  Offers for session address.
