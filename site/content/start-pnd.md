# What is $PND

$PND is the Pond Protocol issued currency on the XRP Ledger. An IOU. Not a
native chain coin, and not $rPND.

<div class="callout callout-critical">
<p><strong>$PND has not launched yet.</strong> Target <strong>1 October 2026</strong>.
No $PND has been issued. A token trading under the three-character code
<code>PND</code> is not automatically this asset.</p>
</div>

## Scan this

- **Identity** is the pair **(currency code, issuer address)** — never the
  ticker alone.
- **Code** is `PND` (those three letters, that case). Codes are
  case-sensitive: `Pnd` is a different asset.
- **Issuer** is the address below. Anyone can issue the code `PND`. Several
  mainnet accounts already have.

<p><code class="addr">{{issuerAddress}}</code></p>

- **Supply** is a **100 billion** working policy, not a ledger-enforced cap.
  High-level split: 10B public, 10B team, 80B to holders later. Details:
  [Supply split](/vesting/).
- **How you opt in** after launch: a trust line (`TrustSet`) in *your*
  wallet to this issuer. That is the [Set Trust Lines](/start/trust-lines/)
  step — not a button on this page.

## What $PND is not

- Not issued today. Nothing to buy.
- Not $rPND. That is a planned MPT, and it is **not** the 1 October 2026
  launch. Next step: [What is $rPND](/start/rpnd/).
- Not a claim, airdrop connect, or seed import. This site will never ask for
  a seed.

The longer holder and integrator pages stay at [$PND](/pnd/). This step is
only the onboarding identity.
