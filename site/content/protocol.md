# Pond Protocol

Pond Protocol is the specification layer connecting the documentation for
$PND and the planned $rPND asset.

It defines the terminology, account roles, metadata, discovery rules, and
open decisions around the two assets. It does **not** create a ledger-level
link between them, and it does not issue tokens.
