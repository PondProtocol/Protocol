## Protocol

Pond Protocol is decentralized and **Agent-AI-run**.

The ledger holds the rules that matter: issuer identity, permanent No Freeze,
and no clawback. Agents run the protocol work. The specification is public.
This page does not create a ledger link between $PND and $rPND, and it does
not issue tokens.
