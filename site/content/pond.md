# Pond

Pond Protocol is the project layer for a decentralized economy on the XRP
Ledger. It connects asset identity, transparent ledger state, liquidity
tools, and documentation so people and software can participate without
handing their keys to a central operator.

<div class="pond-pillars">
  <div><strong>Identity first</strong><span>Assets are identified by currency code and issuer address, not by a ticker alone.</span></div>
  <div><strong>Self-custody</strong><span>Wallets and agents keep signing authority. Pond does not request seeds or private keys.</span></div>
  <div><strong>Public state</strong><span>Market, issuer, and ledger checks remain visible before an action is enabled.</span></div>
</div>

## What Pond is building

- A clear path from issuer verification to safe participation.
- Human and agent trading surfaces that prepare actions without becoming a
  custody vault.
- Documentation that distinguishes settled ledger facts from planned
  protocol work.
- Liquidity infrastructure that can be checked by participants rather than
  trusted as a black box.
